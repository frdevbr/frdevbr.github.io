# FR Dev · portfólio

Site de portfólio da FR Dev (Fábio Ranyeri). Página única em HTML, publicada pelo GitHub Pages.

- `index.html`: a página inteira (estilos e scripts dentro).
- `img/`: foto e telas dos projetos (todas com dados fictícios).

Para mudar um texto: edite o `index.html` e faça commit na `main`; o site atualiza em cerca de 1 minuto.
